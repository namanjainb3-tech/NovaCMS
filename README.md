# 🚀 Overview

NovaCMS is a **modern full-stack Content Management System (CMS)** that enables developers, startups, businesses, and agencies to manage website content through an elegant dashboard instead of modifying source code.

Rather than hardcoding landing pages and manually redeploying for every content update, NovaCMS stores website content inside **MongoDB Atlas**, allowing administrators to update text, images, buttons, sections, and branding from a centralized admin panel.

The project combines a **React frontend**, an **Express REST API**, **MongoDB Atlas**, **Google OAuth**, **JWT Authentication**, and a responsive dashboard into a production-ready CMS that can power marketing websites, startup landing pages, SaaS products, portfolios, and business websites.

Whether you're managing a startup landing page or building websites for multiple clients, NovaCMS dramatically simplifies content management while maintaining complete control over your frontend.

# 🎯 The Problem

Most modern websites still rely on developers for even the smallest content updates.

Changing something as simple as:

- Hero Title
- Hero Description
- CTA Button
- Workflow Section
- Footer Links
- Contact Information
- Company Branding

usually requires:

- Opening the codebase
- Editing React components
- Creating a Git commit
- Deploying the application again

This workflow becomes inefficient for businesses where content changes frequently.

Marketing teams, founders, and clients often depend entirely on developers for updates that should take only a few seconds.

---

# 💡 Our Solution

NovaCMS separates **website content** from **website code**.

Instead of hardcoding text inside React components, content is stored inside MongoDB and managed through an intuitive dashboard.

The workflow becomes:

```
Edit Content

↓

Save Changes

↓

Publish Website

↓

Website Updates Instantly
```

No code modifications.

No rebuilding components.

No editing JSX files.

Simply update content through the dashboard and publish your changes.

# 📡 REST API

## Authentication

### Login using Google

```http
POST /api/auth/google
```

Authenticates administrators using Google OAuth and returns a JWT token.

---

### Email Login

```http
POST /api/auth/login
```

Authenticates users using email and password.

---

## Content

### Get Website Content

```http
GET /api/content
```

Returns every editable section used by the landing page.

---

### Update Section

```http
PUT /api/content/:section
```

Updates a specific website section.

Example:

```text
hero

workflow

cta

footer
```

---

### Publish Website

```http
POST /api/content/publish
```

Publishes the latest content changes.

---

## Upload

### Upload Image

```http
POST /api/upload
```

Uploads website assets such as:

- Logos
- Hero Images
- Icons
- Product Images

---

## Settings

### Get Settings

```http
GET /api/settings
```

Returns global website settings.

---

### Update Settings

```http
PUT /api/settings
```

Updates website configuration.

# 🚀 Getting Started

Follow these instructions to run NovaCMS locally on your machine.

---

# 📦 Clone the Repository

```bash
git clone https://github.com/namanjainb3-tech/NovaCMS.git

cd NovaCMS
```

---

# ⚙ Backend Setup

Navigate to the backend directory.

```bash
cd server
```

---

## Install Dependencies

```bash
npm install
```

---

## Create Environment Variables

Create a file named:

```text
.env
```

Add the following variables.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_super_secret_jwt_key

GOOGLE_CLIENT_ID=your_google_client_id

CLIENT_URL=http://localhost:5173
```

---

## Seed Initial Website Content

Populate the database with the default landing page sections.

```bash
node seedContent.js
```

The script automatically creates the required content documents inside MongoDB.

---

## Start Backend

Development

```bash
npm run dev
```

Production

```bash
npm start
```

Backend runs on

```
http://localhost:5000
```

---

# 🗄 MongoDB Atlas Setup

NovaCMS uses **MongoDB Atlas** as its cloud database.

---

## Create a Cluster

1. Create a free MongoDB Atlas account.

2. Create a new cluster.

3. Create a database user.

4. Whitelist your IP address.

For production deployments, you may temporarily allow:

```
0.0.0.0/0
```

to permit access from hosting providers such as Render.

---

## Obtain Connection String

Atlas provides a connection string similar to:

```text
mongodb+srv://username:password@cluster.mongodb.net/cms_db
```

Paste this into

```env
MONGO_URI=
```

inside the backend `.env`.

# 💡 Design Philosophy

NovaCMS follows a simple philosophy:

> **Content should be editable by anyone. Code should remain untouched.**

Instead of forcing developers to modify React components for every content change, NovaCMS separates **content** from **presentation**, allowing non-technical users to update websites through a secure and intuitive dashboard.

This architecture makes the platform ideal for startups, agencies, freelancers, and businesses that need fast content updates without developer intervention.
